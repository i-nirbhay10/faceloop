# 📱 Real-Time Video Calling App

A cross-platform mobile application built with **React Native** and **Agora SDK** to enable real-time video and audio communication.

## 🚀 Features

- Real-time video/audio calls using Agora
- Channel-based calling
- Join/leave handling for smooth user flow
- Simple and responsive UI
- Works on both Android and iOS
- APK build ready for testing

## 🧰 Tech Stack

- React Native
- Agora SDK
- JavaScript
